## 特点

- **六个网站**：煤炉 Mercari、雅虎拍卖、雅虎闲置、乐天 Rakuma、骏河屋、Mandarake
- **按你的条件筛**：关键词、价格区间、标题必含词和排除词，可选降价提醒
- **十种推送**：Server酱、PushPlus、企业微信、钉钉、飞书、Bark、ntfy、Telegram、邮件、Webhook
- **不刷屏**：新加的关注先记下现有商品，只推之后的新上架；同一件商品只推一次
- **本地网页**：看上新、管关注、配推送；加关注前可以先预览搜索结果
- **开箱即用**：只用 Python 标准库，什么都不用装；所有数据只存在你自己的电脑上

## 快速开始

1. 安装 [Python 3.9 或更新版本](https://www.python.org/downloads/)。Windows 安装时勾选 **Add python.exe to PATH**。
2. [下载本项目](https://github.com/lxy3312/goodsmare/archive/refs/heads/main.zip)并解压。
3. Windows 双击 `start.bat`；macOS / Linux 运行 `./start.sh`。
4. 浏览器会自动打开 <http://127.0.0.1:8787>。在「关注」里填关键词，在「推送」里配好渠道，点「发一条测试」。

窗口开着就会一直扫描。推送渠道怎么选、命令行、放到 NAS 上长期运行等，见[使用指南](docs/guide.md)。

## 工作原理

每隔一段时间（默认 3 分钟），去各网站搜索按上架时间排序的第一页，和本地数据库里见过的商品比对：没见过的是上新，比上次便宜的是降价。按你的条件过滤后，合成一条推送发出。

同一个网站的两次请求之间留有间隔，不同网站并行扫描，互不影响。
