手机打不开？
  1. 手机和电脑要连同一个 Wi-Fi，手机别用流量。
  2. 第一次打开开关时 Windows 会弹出防火墙提示，要点「允许访问」。当时点了取消的话：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙，把 Python 的「专用」和「公用」都勾上。
  3. Windows 把这个 Wi-Fi 当成「公用网络」时也会挡住，可以在 设置 → 网络和 Internet 里把它改成「专用网络」。
  4. 路由器开了「AP 隔离」或者手机连的是访客网络，手机和电脑互相看不见。
  5. 上面列了好几个地址的话，换一个试试。
